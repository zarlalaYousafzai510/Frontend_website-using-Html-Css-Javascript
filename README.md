# Frontend Development Best Practices

## About
A responsive and interactive website built using HTML, CSS, and JavaScript to practice frontend development best practices.

## Features
- Responsive navigation menu
- Responsive layouts for different screen sizes
- Smooth scrolling and animations
- Interactive service content
- Contact form with client-side validation
- Mobile-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Files
- `index.html` — Website structure
- `style.css` — Styling and responsive design
- `script.js` — Interactive features and form validation

## Note
This is a frontend-only project. The contact form does not send data to a server.
